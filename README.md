# Platypub (WIP)

This is the start of a newsletter/blogging platform aimed at people who _aren't_
trying to make money from their writing. Kind of like Tinyletter before it got
acquired and shut down. Planned features (these are early ideas and may change
as Platypub progresses):

- Easily add newsletter functionality to an existing/external blog: enter your
  website URL/RSS URL, then embed a signup form on your website or link to a
  hosted signup page. Subscribers get an email whenever your RSS feed has a new
  post.

- Publish a website with content sourced from a git repo. (And/or google docs,
  or...?)

- A builtin CMS so you can make a new blog+newsletter all within Platypub.

- Pricing model that's compatible with casual/non-commercial writing: free tier
  with X email sends per month, subsequent pricing is based purely on usage
  instead of # of publications or # of subscribers, one-time fee to import
  subscribers (necessary to combat spam).

- Custom themes are arbitrary code that ingest your posts and output a pile of
  html etc. Platypub runs the code in a sandbox.
