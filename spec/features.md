# Platypub MVP

This is a lightweight publishing app. It lets people add email newsletter
functionality to an existing blog that they host elsewhere.

Features:

- [Signup](features/signup.md)
- [Create a publication](features/create-a-publication.md)
- [Importing subscribers](features/importing-subscribers.md)
- [Viewing posts](features/viewing-posts.md)
- [Subscribing](features/subscribing.md)
- [Sending emails](features/sending-emails.md)
- [Feed syncing](features/feed-syncing.md)
- [Subscriber management](features/subscriber-management.md)
- [Email providers](features/email-providers.md)
- [Email rendering](features/email-rendering.md)
