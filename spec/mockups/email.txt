Email with one post, Card (default):


  <linked publication banner, if set>
  +-----------------------------------------+
  | <intro, if set>                         |
  | # My Post                               |
  | [link: Read online, if post URL is set] |
  | <full post content>                     |
  | <address>. [link: Unsubscribe].         |
  +-----------------------------------------+


Email with one post, Letter:


  <wide linked publication banner, if set>
  <intro, if set>
  # [link: My Post]
  <full post content>
  -------------------------------------------
  <address>. [link: Unsubscribe].


Email with multiple posts, always Card:


  <linked publication banner, if set>
  +-----------------------------------------+
  | # My Publication                        |
  | <intro, if set>                         |
  | <shared author info, if all match>      |
  |                                         |
  | [link: <post name>]                     |
  | <author info, if different>             |
  | <excerpt>... [link: Read more]          |
  | <published at>                          |
  |                                         |
  | [link: <next post name>]                |
  | <excerpt>... [link: Read more]          |
  | <published at>                          |
  |                                         |
  | <address>. [link: Unsubscribe].         |
  +-----------------------------------------+


A post without a URL shows its full content in the multi-post card.

The address is formatted as a single line. The intro is rendered in italics if
set. The publication colors, banner image, website URL, and mailing address
are used in both styles.
