  ## Archive publication

  If you archive this publication, the subscribe forms will be disabled and no
  emails will be sent to existing subscribers.

  [Archive publication]


Each preview button opens a modal that renders the data currently in the form,
even if it hasn't been saved yet.

Notes on settings form fields:

- `address` is a single-line text input.

`Archive publication` opens a confirmation modal. After confirming, the user is
redirected back to the publication list page.
